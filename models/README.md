# Serialized Model Artifacts & Pipelines

This directory contains trained, serialized scikit-learn and XGBoost pipelines, evaluation metadata, and feature schemas generated by the end-to-end employee attrition prediction pipeline.

## 1. Artifact Contents
Upon executing the training pipeline (`python run_pipeline.py` or the notebook `notebooks/employee_attrition_prediction.ipynb`), the following artifacts are persisted:

- **`best_model_pipeline.joblib`**: The selected production pipeline (Random Forest Classifier) containing fitted preprocessing (`ColumnTransformer`) and model weights.
- **`model_metadata.json`**: Technical configuration containing best hyperparameters, CV scores, test set metrics, feature names, training duration, and random state.
- **`logistic_regression_pipeline.joblib`**: Tuned Logistic Regression model pipeline.
- **`decision_tree_pipeline.joblib`**: Tuned Decision Tree model pipeline.
- **`random_forest_pipeline.joblib`**: Tuned Random Forest model pipeline.
- **`xgboost_pipeline.joblib`**: Tuned XGBoost model pipeline.

## 2. Model Loading & Inference Example
To load a saved model pipeline and score new employee records:

```python
import pandas as pd
from src.utils import load_joblib_artifact

# Load production pipeline (includes both ColumnTransformer preprocessing and classifier)
pipeline = load_joblib_artifact("models/best_model_pipeline.joblib")

# Sample employee input data (raw dataframe format matching feature schema)
sample_employee = pd.DataFrame([{
    "Department": "Sales",
    "JobRole": "Sales Executive",
    "Age": 32,
    "Gender": "Female",
    "EducationLevel": "Bachelor",
    "JobLevel": 2,
    "MonthlyIncome": 5400,
    "TotalWorkingYears": 8,
    "YearsAtCompany": 4,
    "YearsInCurrentRole": 2,
    "YearsSinceLastPromotion": 1,
    "YearsWithCurrManager": 2,
    "TrainingTimesLastYear": 3,
    "JobSatisfaction": 2,
    "EnvironmentSatisfaction": 2,
    "WorkLifeBalance": 2,
    "PerformanceRating": 3,
    "Overtime": "Yes",
    "BusinessTravel": "Travel_Frequently",
    "AbsenteeismDays": 5
}])

# Generate predictions
predicted_class = pipeline.predict(sample_employee)[0] # 1 = Attrition risk, 0 = Retained
predicted_proba = pipeline.predict_proba(sample_employee)[0, 1] # Probability of departure

print(f"Predicted Attrition Risk: {'High Risk' if predicted_class == 1 else 'Low Risk'}")
print(f"Predicted Probability of Departure: {predicted_proba:.2%}")
```
